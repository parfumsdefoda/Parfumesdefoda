# Parfums De Foda — متجر العطور الفاخرة

## عن المشروع

موقع إلكتروني لمتجر Parfums De Foda للعطور الفاخرة. تم بناء الموقع باستخدام أحدث التقنيات لضمان السرعة والأداء وسهولة الاستخدام.

## متطلبات التشغيل

- **Node.js** الإصدار 18 أو أحدث
- **npm** (يأتي مع Node.js)

## كيفية تشغيل المشروع

### 1. تثبيت الاعتماديات

```bash
npm install
```

### 2. تشغيل خادم التطوير

```bash
npm run dev
```

بعد التشغيل، افتح الرابط: http://localhost:3000

### 3. بناء النسخة النهائية

```bash
npm run build
```

### 4. تشغيل النسخة النهائية

```bash
npm start
```

## هيكل المجلدات

```
parfumsdefoda/

├── data/          # ملفات البيانات القابلة للتعديل

## كيفية إدارة الموقع

### إضافة منتج جديد

## إضافة منتج جديد

1. افتح الملف:

```text
public/data/products.json
```

2. انسخ آخر منتج وقم بتعديل البيانات التالية فقط:

- id
- slug
- sku
- اسم العطر
- الوصف
- التصنيفات
- الصورة
- الأسعار
- المخزون
- النوتات العطرية

3. ضع صورة المنتج داخل:

```text
public/products/
```

مثال:
```text
public/products/p005.webp
```
ثم داخل المنتج اكتب:

```json
"image": "/products/p005.webp"
```
إذا كان للعطر أكثر من صورة:

```json
"gallery": [
  "/products/p005.webp",
  "/products/p005-2.webp",
  "/products/p005-3.webp"
]
```
---

### المقاسات المدعومة

```json
"sizes": [
  {
    "label": "50 مل",
    "price": 600,
    "stock": 20
  },
  {
    "label": "30 مل",
    "price": 420,
    "stock": 25
  },
  {
    "label": "عينة 2.5 مل",
    "price": 60,
    "stock": 100
  }
]

---

### نوع الكارت

العادي
```json
"type": "normal"
```
الكارت الذهبي (نيش)
```json
"type": "gold"
```
---
### الشارة
جديد
```json
"badge": "new"
```
الأكثر مبيعًا
```json
"badge": "bestSeller"
```
بدون شارة
```json
"badge": ""
```
---
### التفعيل
ظاهر بالموقع
```json
"status": "active"
مخفي
```json
"status": "hidden"
---

### حذف منتج

1. افتح `data/products.json`
2. احذف الكتلة الخاصة بالمنتج بالكامل (من `{` إلى `}`)
3. احفظ الملف

### تغيير السعر

1. افتح `data/products.json`
2. ابحث عن المنتج المطلوب باستخدام `id`
3. غيّر قيمة `price` داخل `sizes`
4. احفظ الملف

### تغيير الألوان

1. افتح `data/theme.json`
2. غيّر قيم الألوان:
   - `primary`: اللون الرئيسي (خلفية بيضاء)
   - `secondary`: اللون الثانوي (أخضر)
   - `accent`: لون العلامة التجارية (بنفسجي)
   - `gold`: اللون الذهبي
3. احفظ الملف

### تغيير رقم واتساب

1. افتح `data/contact.json`
2. غيّر قيمة `whatsapp` إلى الرقم الجديد (بدون + أو 00)
3. احفظ الملف

### تغيير البريد الإلكتروني

1. افتح `data/contact.json`
2. غيّر قيمة `email`
3. احفظ الملف

### تغيير روابط التواصل الاجتماعي

1. افتح `data/social.json`
2. غيّر الروابط المطلوبة
3. احفظ الملف

### تحديث الأسئلة الشائعة

1. افتح `content/faq.json`
2. أضف أو احذف الأسئلة حسب الحاجة
3. احفظ الملف

### تحديث سياسات المتجر

1. افتح `content/policies.json`
2. غيّر النصوص حسب الحاجة
3. احفظ الملف

### تحديث معلومات تحسين محركات البحث (SEO)

1. افتح `data/seo.json`
2. غيّر العنوان والوصف والكلمات المفتاحية
3. احفظ الملف

### تغيير صورة المنتج

1. ضع الصورة الجديدة في مجلد `public/products/`
2. تأكد من أن اسم الملف يطابق القيمة في `image` داخل `data/products.json`
3. الصيغة الموصى بها: WebP

## أوامر مفيدة

| الأمر | الوصف |
|-------|--------|
| `npm run dev` | تشغيل خادم التطوير |
| `npm run build` | بناء النسخة النهائية |
| `npm start` | تشغيل النسخة النهائية |
| `npm run lint` | التحقق من جودة الكود |
| `npm run typecheck` | التحقق من أنواع TypeScript |
| `npm run validate-json` | التحقق من صحة ملفات JSON |

## النشر على Hostinger

1. شغّل الأمر: `npm run build`
2. ارفع المجلدات التالية إلى Hostinger:
   - `.next/`
   - `public/`
   - `package.json`
   - `next.config.ts`
   - `node_modules/` (أو شغّل `npm install` على الخادم)
3. في لوحة تحكم Hostinger، اختر Node.js كبيئة تشغيل
4. حدد ملف الدخول: `node_modules/.bin/next start`
5. أعد تشغيل التطبيق

## ملاحظات مهمة

- لا تقم بتعديل أي ملف في مجلد `src/` إلا إذا كنت مطوراً
- كل التعديلات اليومية تتم عبر ملفات JSON في `data/` و `content/`
- تأكد من عمل نسخة احتياطية من الملفات قبل التعديل
- إذا حدث خطأ، يمكنك استعادة الملفات من النسخة الاحتياطية
