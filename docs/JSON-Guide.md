# JSON Guide — Parfums De Foda

The owner manages the store by editing JSON files. No TypeScript editing is required for common tasks.

## Quick Reference

| Task | File |
|------|------|
| Add a product | `data/products.json` |
| Change price | `data/products.json` (sizes array) |
| Change colors | `data/theme.json` |
| Change WhatsApp | `data/contact.json` |
| Change Email | `data/contact.json` |
| Change store name | `data/settings.json` |
| Update FAQ | `content/faq.json` |
| Update policies | `content/policies.json` |
| Update SEO | `data/seo.json` |
| Update social links | `data/social.json` |
