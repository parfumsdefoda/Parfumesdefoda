## 1) الحكم / Verdict

**GO مشروط — CONDITIONAL GO.**

لا يوجد عيب وظيفي أو أمني مفتوح في مسار الشراء: 7 عيوب أُصلحت (منها 4 بدرجة S2)، و463 اختبار وحدة و69 اختبار E2E
تمر ثلاث مرات متتالية، و34 حالة صفحة/حالة تخلو تمامًا من مخالفات axe.

الشروط قبل الإطلاق:

1. **ميزانية JavaScript** لم تتحقق: 260–284 KiB أول تحميل مقابل 240 المستهدفة (كانت 250–265 قبل هذا الفرع، أي أن
   التجاوز سابق وليس جديدًا؛ أضاف هذا الفرع +11 KiB لشريط البحث والمساعد). يحتاج قرار المالك أو مهمة تالية.
2. **Lighthouse PDP = 88** مقابل هدف 90 (قبل الفرع كان 87–89؛ ليس انحدارًا، لكنه لا يزال تحت الهدف).
3. **صورة pf241 مفقودة**، فلا يمكن إنشاء النسخة الفاخرة «تيروني» من ملف المالك.
4. **11 صورة تحتاج قصًّا** (9 منها ظاهرة: pf091، pf290، pf480، pf570، pf600، pf630، pf680، pf700، pf720؛ والمخفيتان pf571 وpf572) — مسجّلة في `.audit/needs-retouch.txt` وتُخدَم الآن كإطار كامل مع خلفيتها الملونة.

A conditional GO: every purchase path, accessibility state and link is sound, and the seven defects below are fixed
with proofs. The two performance targets are the only measurable misses and neither regressed on this branch.

## 4) البيانات / Data issues

هذه ليست أخطاء كود — تحتاج قرار المالك:

1. **pf241 «تيروني» غير مُنشأ** — الصف موجود في `data/product-master.csv` (100=950، 50=700، 30=500، 10=220؛
   المتاح 30 و10 فقط) لكن `/public/products/PF241.png` غير موجود، لذلك يرفض المستورد إنشاءه (قاعدة صارمة).
2. **pf670 «عنبر عود»** مخفي (حُذف صفه من الملف) لكن `data/products.json` ما زال يشير إلى `/products/PF670.png`
   المحذوف. لا يظهر للزائر (صفحته 404)، لكن إعادة إظهاره ستكسر صورته.
3. **روابط `is_similar` أحادية/لمخفِيّ**: pf050 (مخفي) → pf740، pf560 (مخفيان)؛ pf091 → pf090 بلا رابط عكسي.
   الموقع يعاملها كعلاقة متبادلة وقت العرض، لكن الوarnings تظل قائمة في كل استيراد.
4. **عمود `season` غائب** عن الملف (مسموح ومُوثَّق)؛ منتجان ظاهران بلا موسم، والفلاتر تعمل.
5. **صور تحتاج قصًّا**: القائمة الرسمية (11 صفًا، منها 9 ظاهرة) في `.audit/needs-retouch.txt`:
   pf091، pf290، pf480، pf570، pf600، pf630، pf680، pf700، pf720، واثنتان مخفيتان (pf571، pf572).

```bash
npm ci
npm run validate-json
npm run check:tokens
npm run check:derived
npm run typecheck
npm run lint
npm run test
npm run build
# خادم إنتاجي محلي للتحقق النهائي (بلا مفاتيح قنوات):
```

1. ميزانية JS وLighthouse PDP (OPEN-1/2) — تحسينات أداء مقترحة، ليست أعطالًا.
