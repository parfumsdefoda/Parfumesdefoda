# Design System — Parfums De Foda

## Brand Colors

| Token | Value | Usage |
|-------|-------|-------|
| Primary | `#FFFFFF` | Background, cards |
| Secondary | `#9CD676` | Buttons, active states |
| Accent | `#632989` | Brand color, headings |
| Gold | `#D4AF37` | Niche cards, premium badges |

## Typography

- Font: Cairo (via `next/font`, Arabic subset)
- Weights: 300 (light), 400 (regular), 500 (medium), 600 (semi-bold), 700 (bold), 800 (extra-bold)
- Headings: Large, generous whitespace, editorial proportions

## Spacing

8pt system. All spacing values are multiples of 0.5rem (8px).

## Component Specs

See Shadcn/UI documentation for base component APIs. Custom components are in `src/features/{name}/components/`.
