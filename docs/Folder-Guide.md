# Folder Guide — Parfums De Foda

| Path | Purpose |
|------|---------|
| `data/` | Editable operational JSON (products, settings, theme) |
| `content/` | Editable content JSON (homepage, FAQ, policies) |
| `locales/` | Arabic text strings |
| `src/app/` | Next.js App Router pages and layout |
| `src/features/` | Feature modules (home, products, filters, cart, checkout, faq, policies, shared) |
| `src/lib/` | Utility functions (utils, whatsapp, email, currency, storage) |
| `src/services/` | Data fetching services (products, settings, seo, orders) |
| `src/types/` | Global TypeScript types |
| `src/schemas/` | Zod validation schemas |
| `src/providers/` | React Context providers |
| `src/store/` | Future Zustand stores |
| `src/config/` | Site configuration constants |
| `public/` | Static assets (logos, products, patterns, icons, etc.) |
| `tests/` | Unit, integration, and E2E tests |
| `scripts/` | JSON validation, build scripts |
| `docs/` | Documentation files |
